# モデリング特訓 6日目

モデリング特訓6日目の振り返りと、その中で得られた学びや気づきをメモとしてまとめておきます。

## モデルの作成

今回は、実際にアクセサリーのモデリングにも挑戦してみようと思い、いちごのイヤリングを作ることにしました。普段はキャラクター本体や衣装を作ることが多いですが、アクセサリーは小物ならではの工夫や難しさがあって新鮮です。

まだ作業途中ではありますが、現時点でのモデルはこんな感じになっています。

![アニメーターのTab](/assets/01993432-5137-7158-bc31-dddde6f60683/image.webp)

まずは、いちごの葉っぱの元となる部分と、果肉部分を作成しました。形状のバランスや全体のシルエットを意識しながら、細かい部分も丁寧に作るよう心がけています。

果肉部分についてですが、普通のいちごだと表面にたくさんの種がついています。
ただ、これをモデリングで再現しようとすると三角ポリゴンの数が一気に増えてしまい、データが重くなってしまいます。
そこで、今回は種の表現はShader側で実装することにしました。

葉っぱの部分については、まずUV展開を行い、その後で形を変形させて果肉部分にくっつける予定です。
ただ、正直なところ作業が少し飽きてしまったので、UV展開の作業は数日以内にやることにします。

### メモ

- 法線マッピング（バンプマッピング）  
  モデルの表面に細かい凹凸を表現するための技術。ポリゴン数を増やさずにディテールを追加できるので便利。
- 視差マッピング  
  テクスチャの奥行き感をよりリアルに見せるための手法。バンプマッピングよりも立体感が強調される。
- セルフシャドウ付き視差遮断マッピング  
  視差マッピングに加えて、自己影（セルフシャドウ）も表現できる高度な技術。よりリアルな質感を目指す場合に有効。
